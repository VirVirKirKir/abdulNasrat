# Формат данных

## 1. JSON-лента (настройки → «JSON-лента»)

Приложение делает `GET` по URL и ждёт JSON:

```json
{
  "alerts": [
    {
      "id": "orenburg-2026-11-22-1840",
      "kind": "uav_threat",
      "issuedAt": "2026-11-22T18:40:00Z",
      "text": "Внимание! Угроза БПЛА...",
      "source": "МЧС Оренбургской области"
    }
  ]
}
```

Поддерживаются также ключи `events` / `items` вместо `alerts`.

### Поля

| Поле | Обязательно | Описание |
|---|---|---|
| `id` | нет | Уникальный ID. Без него собирается из типа и времени. |
| `kind` | да | Тип события, см. ниже. |
| `issuedAt` | нет | ISO-8601 (`2026-11-22T18:40:00Z`) или `timestamp` (сек/мс). |
| `text` | нет | Исходный текст (показывается в истории). |
| `source` | нет | Подпись источника. |

### Значения `kind`

| `kind` | Смысл |
|---|---|
| `uav_threat` | Угроза БПЛА |
| `missile_threat` | Ракетная опасность |
| `uav_all_clear` | Отбой угрозы БПЛА |
| `missile_all_clear` | Отбой ракетной опасности |
| `sirens_on` | Звучат сирены (играет `sirens.caf`) |
| `sirens_off` | Отбой воздушной тревоги |

Синонимы: `uav`, `drone`, `bpla`, `missile`, `rocket`, `sirens`, `all_clear` и т.п.

Дедупликация идёт по `id`, поэтому один и тот же ID повторно уведомление не вызовет.

### Минимальный сервер на Node (без зависимостей)

```js
import http from "node:http";

const alerts = [];

http.createServer((req, res) => {
  if (req.url === "/alerts") {
    res.writeHead(200, { "content-type": "application/json; charset=utf-8" });
    res.end(JSON.stringify({ alerts }));
    return;
  }
  res.writeHead(404).end();
}).listen(8080);
```

## 2. Telegram

Приложение читает публичную страницу `https://t.me/s/<channel>` — без API-ключей и без бота.

- Канал должен быть **публичным**.
- Сообщения классифицируются по ключевым словам:
  - отбой + «ракетн» → отбой ракетной опасности
  - отбой + «бпла/беспилот/дрон» → отбой БПЛА
  - «сирен» (без «отбой») → сирены
  - «ракетн» + «опасн/угроз» → ракетная опасность
  - «бпла/беспилот/дрон» + «опасн/угроз/летят/курс» → угроза БПЛА
- Флаг «Только сообщения про Оренбург» фильтрует по слову «оренбург».
- Диагностика показывает HTTP-код и число распознанных сообщений — по ней видно, живой ли канал.

## 3. Push (когда приложение закрыто)

Локальные уведомления работают только пока приложение запущено или ему дали фон. Для мгновенных push нужен:

1. Платный Apple Developer Program (APNs-ключ `.p8`, `keyId`, `teamId`).
2. Сервер, который следит за источником и шлёт push.
3. В приложении — регистрация на `didRegisterForRemoteNotificationsWithDeviceToken` и отправка токена на сервер.

Заготовка сервера — в папке `server/`.
